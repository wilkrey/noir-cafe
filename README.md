# NOIR Café

Демонстрационный концепт вымышленной specialty-кофейни для портфолио веб-студии.
**Это не реальное заведение.** Адреса, телефоны, цены, отзывы и цитаты выдуманы.

## Запуск

Нужен Node.js 18+. Зависимости не требуются.

```bash
npm start            # http://localhost:4173
PORT=8080 npm start  # другой порт
npm run check        # проверка синтаксиса, ссылок, id и тегов
```

## Что внутри

Арт-дирекшен «Modern Soft Luxury»: молочный фон, эспрессо как основной тёмный цвет, карамель как точечный акцент, мягкие скругления 16–32px, неглубокие тени, крупные фото. Заголовки — Fraunces, текст и интерфейс — Inter.
Подробное описание решений, токены и история аудита — в [docs/ART-DIRECTION.md](docs/ART-DIRECTION.md).

Движение: intro hero, появление блоков один раз, параллакс только на двух фото на desktop, счёт цифр, индикатор вкладок, состояния кнопок. Всё отключается при `prefers-reduced-motion`; без JS контент виден сразу. Подробности — в [docs/ART-DIRECTION.md](docs/ART-DIRECTION.md).

Разделы страницы: hero с фотографией и карточкой адреса, о кофейне, меню с вкладками, пространство (галерея), процесс обжарки в тёмном блоке, визит с формой бронирования, призыв и футер. На мобильных — шторка меню и нижняя панель действий «Меню · Визит · Бронь».

## Структура

```
index.html              разметка всех разделов
assets/favicon.svg
docs/ART-DIRECTION.md  арт-дирекшен, токены, аудит
src/styles/
  tokens.css            цвета, скругления, тени, типографика, сетка, движение
  base.css              reset, типографика, кнопки, сетка 12 колонок

  modules/
    nav.js              шапка, мобильное меню, фокус-ловушка, Esc
    menu-tabs.js        вкладки меню (ARIA tablist, стрелки, Home/End)

  check.mjs             проверка проекта
```

## Фотографии

Фото загружаются напрямую с Unsplash (`images.unsplash.com`), лицензия Unsplash License: бесплатно для коммерческого использования. Для замены найдите нужный адрес `https://images.unsplash.com/photo-…` в `index.html` и подставьте свой файл. Параметры `w=` задают ширину для `srcset`.

Для показа сайта нужен доступ к `images.unsplash.com`. Без него фото не загрузятся, а на их месте будут пустые блоки.

## Формы и интеграции

Форма бронирования демонстрационная: заявка никуда не отправляется, это сказано прямо на странице. Для реального использования замените блок с `setTimeout` в `src/js/modules/reservation-form.js` на запрос к вашему API.

Социальных сетей на сайте нет: аккаунтов нет, ссылки-заглушки удалены.

Шрифты Fraunces и Inter подключаются с Google Fonts. Без сети используются системные запасные шрифты.
